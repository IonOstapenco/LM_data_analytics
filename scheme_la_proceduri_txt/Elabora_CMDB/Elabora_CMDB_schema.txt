## ⚠️ 2. Asset ServerDismessi → DISMESSI

Aici trebuie modificat.

Schema ta spune:

```
Asset ServerDismessi (ALL)*.csv → DISMESSI

DISS_field:
- server
- datadismissione
```

Dar în cod actual:

```python
#DISS_data = process_asset(...)
```

este comentat.

Mai mult:

```python
#DISS_field = ["server","datadismissione"]
```

este și el comentat.

Deci această parte **nu mai face parte din fluxul actual**.

În schimb eliminarea serverelor dezafectate se face direct din:

```
Asset Server (ALL)
```

prin:

```python
stato = row.get("Stato", "")

if stato == "Dismesso":
    continue
```

Deci schema corectă ar fi:

```
Asset Server (ALL)*.csv
          |
          |
          ▼
Filtru:
Stato != Dismesso
```

Nu mai există fișier separat pentru Dismessi.
